# Vallore — latest Shopify theme package

Built from the exact latest website preview, version 5, including the 4.5-star rating, Dr. Aria Wang endorsement, current bundle prices of $32.99 / $49.99 / $59.99 and crossed-out former prices of $65.98 / $99.98 / $119.98. Blueberry, the four replacement videos, unchanged third video, all-five desktop layout, mobile ritual placement, and review carousel are preserved. No redesign.

## Upload to GitHub
Extract the ZIP, then upload its CONTENTS directly into your repository root. The root should contain assets/, config/, layout/, locales/, sections/, snippets/, and templates/. Do not upload the ZIP itself or put an extra parent folder around these directories.

## Shopify
Connect your theme repository from Shopify Online Store > Themes. Preview before publishing.

## Checkout
This packages the existing preview exactly. Its cart drawer, prices, and checkout remain preview behavior. Live Shopify products, variants, bundles, selling plans, and checkout are not connected. That integration is required before accepting orders.

## Editing
Markup: snippets/vallore-storefront.liquid. Styles: assets/vallore.css. Interactions: assets/vallore.js.liquid. Homepage and product templates both render the storefront section. All images and five videos are separate files in assets/.

## Validation
JavaScript syntax, JSON, section references, and extracted asset hashes checked locally. Shopify upload and visual preview in the actual store have not been tested.
